# iPhone Codex 最小验证项目

中文手机待办网页：新增、完成/取消完成、删除、浏览器 localStorage 保存。

## 运行

在仓库根目录执行：

```sh
python -m http.server 8765 --directory todo --bind 0.0.0.0
```

云端的 localhost 不代表 iPhone；手机访问需要受支持的端口转发或托管网址。
项目无依赖、无付费 API、无服务端数据库。数据保存在访问者当前浏览器，清除网站数据会丢失，不跨设备同步。
